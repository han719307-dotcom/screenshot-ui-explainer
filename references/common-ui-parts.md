# 常见界面部件速查

拆解截图、给元素命名时对照本表。目的是**命名统一 + 别漏掉信息量大的元素**。

## 顶部导航栏（Top bar / Header）

| 部件 | 英文 | 典型用途 |
|---|---|---|
| 汉堡菜单 | Hamburger menu / ☰ | 收起展开侧边栏 |
| 品牌徽标 | Logo / Brand mark | 回全局首页 |
| 页面标题 / 面包屑 | Page title / Breadcrumb | 标明当前位置 |
| 全局搜索 | Global search | 搜全局资源，常带快捷键提示（如 `Type / to search`） |
| 新建按钮 | New / Create / `+` | 建仓库、建文档、导入等，常带下拉菜单 |
| 通知 / 收件箱 | Notifications / Inbox | 消息、提及、系统通知 |
| 帮助 / 设置 | Help / Settings | 齿轮或问号图标 |
| 头像菜单 | Avatar / Profile menu | 账号、切换账户、退出登录 |

**注意**：顶栏右侧常是一串**并排的图标按钮**（如 Issues、Pull requests、仓库入口），
宽度都在 20-50px，容易被当成装饰漏掉。逐个放大确认含义。

## 左侧边栏（Sidebar）

| 部件 | 说明 |
|---|---|
| 主导航项 | Home / Feed / Explore 等，**当前项通常有高亮背景条**，是重要的状态信息 |
| 收藏 / 置顶 | Starred / Pinned |
| 列表区 | 仓库列表、项目列表、频道列表等 |
| 空状态 | `No xxx found` —— 说明"本该有但当前没有"，是重要状态信息，务必标注 |
| 底部 | 用量、升级入口、设置 |

## 主内容区

| 部件 | 说明 |
|---|---|
| 欢迎语 | 常包含用户名，可用于确认当前登录账号 |
| 输入框 / 编辑区 | 关注 placeholder 文案，它常写明用法（如"输入 @ 添加上下文"） |
| 模式选择器 | Ask / Agent / Plan 等，切换交互模式 |
| 范围选择器 | All repositories / 当前项目 等，限定上下文范围 |
| 发送 / 提交 | 纸飞机、箭头图标 |
| 快捷操作行 | 一排胶囊按钮，把高频任务前置；带 `▾` 的表示有二级菜单 |
| 推荐卡片 | Playlist、文档、公告等，右上角常有 `×` 关闭 |
| 任务清单 | Getting started / Onboarding |
| 进度指示 | `0/3 complete` 形式的进度条 + 文字 |
| 折叠项 | 左侧 `>` / `v` 箭头控制展开收起 |
| 主操作按钮 | 通常是**彩色实心按钮**（Create、Save、Continue） |
| 更多操作 | `⋯` 三点菜单 |

## 表格 / 列表

表头（可排序）、行内操作按钮、分页器、每页条数选择、全选复选框、状态标签（Badge / Tag）。
状态标签的颜色通常有语义（绿=成功、黄=警告、红=错误），值得在 desc 里点出。

## 表单

输入框（含必填星号、placeholder、字数限制）、下拉选择、单选/多选、开关（Toggle）、
日期选择、文件上传、帮助提示（`?` 图标）、校验错误提示、提交/取消按钮。

## 弹窗 / 模态框

标题栏、关闭 `×`、内容区、底部操作按钮组（主操作在右）、遮罩层。
若有危险操作确认，注意区分主按钮颜色。

## 需要特别留意的高信息量元素

这些元素"长得不显眼但信息量大"，是最容易被漏标的一类：

1. **空状态文案** —— `No repositories found`、`暂无数据`，直接反映当前账号/项目的真实状态。
2. **进度与计数** —— `0/3 complete`、`3 项待处理`。
3. **当前选中态** —— 侧栏高亮、Tab 选中下划线。
4. **禁用态** —— 灰色按钮，说明前置条件未满足。
5. **快捷键提示** —— placeholder 里的 `/`、`⌘K`。
6. **数字角标** —— 图标右上角的红色小数字，表示未读数。
7. **账号标识** —— 头像、用户名、组织名，用于确认"这是谁的界面"。

## 命名规范

- 采用 `英文原名（中文解释）`：`Pull requests（拉取请求）`、`Inbox 通知`。
- **按原界面文字命名**，不要自行改写成同义词，用户对着截图才能一一对应。
- 图标类元素若界面无文字，用通用名 + 形状描述：`方形书签图标`、`圆形设置图标`。
- 拿不准的元素**先放大确认再命名**，宁可写「疑似」也不要编造功能。
